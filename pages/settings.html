Snake Eye reads a bundled JSON universe. A market data provider needs an API key, and a key cannot live in frontend code — Stage 4 adds a small backend that holds the key and serves the same shape this file has.

Roadmap

Demo data. Everything in this build is generated for development. For real use, the delay of the market feed, data quality, exchange licensing, trading fees and risk all have to be accounted for.
